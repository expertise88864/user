1. Definition & Classification（定義與分類）

EBA 是罕見的 autoimmune subepidermal bullous disease，由針對 Type VII collagen（anchoring fibril 內的 collagen）的 IgG autoantibodies104-26 105-49 113-38 引起；病因不明，但多數證據提示（suggests）autoimmune etiology。p.971

  • Anchoring fibrils 位於 dermal–epidermal junction（DEJ），把 epidermis 及其下的 basement membrane zone（BMZ）固定到 papillary dermis。p.971
  • EBA 是後天疾病、通常在成年發病；因為臨床病灶與兒童遺傳性 dystrophic EB 極為相似，一百多年前就被歸入 epidermolysis bullosa 這個類別。p.971
  • At-a-glance：skin fragility、subepidermal blisters、residual scarring、milia；常見部位是易受外傷處，包括手、腳、肘、膝、sacrum、指甲與口腔。可能合併 inflammatory bowel disease 等系統性疾病，也可能有黏膜糜爛與 esophageal stenosis；治療選擇有限且常很困難。p.971

2. Epidemiology（流行病學）

  • EBA 是 sporadic autoimmune bullous disease；沒有 gender、racial、ethnic 或 geographical predisposition。p.971
  • 美國東南部的 African American 族群可能有某種 genetic predisposition；該地區罹患 EBA 或 bullous SLE 的 African American 病人 HLA-DR2 phenotype 的比例高，HLA-DR2+ 者罹患 EBA 的 calculated relative risk 為 13.1。作者認為這提示 EBA 與 bullous SLE 在 immunogenetics 上相關。p.971
  • 另一項 HLA genotype 研究發現 HLA-DRB1*15:03 過度表現（overrepresented）。p.971
  • EBA 極為罕見，比其他自體免疫水疱病（bullous pemphigoid、pemphigus vulgaris、dermatitis herpetiformis 等）更少見。在血中有 anti-BMZ autoantibody 的 unselected bullous disease 病人中，約 5% 為 EBA 或 bullous SLE。p.971
  • 法國前瞻性研究（以 electron 與 immune-electron microscopy 確診）：incidence 為 0.17 至 0.26 per million people，只佔所有 subepidermal autoimmune bullous disease 病人的 2% 至 3%；德國某地區 incidence 為 0.17。p.971
  • 主動誘發的小鼠 EBA 模型（以 murine Type VII collagen 免疫）是否發病取決於小鼠品系。p.971

McKee 補充：EBA 通常在成年發病，但有兒童病例；法國與德國中部的年發生率同為 0.17–0.26 per million；EBA 病人 MHC class II haplotype HLA-DR2 頻率增加。McKee p.156

3. Etiology & Pathogenesis（病因與致病機轉）

抗原：Type VII collagen

  • IgG autoantibodies 針對 anchoring fibrils 內的 Type VII collagen，與 BMZ 上正常 anchoring fibrils 缺乏（paucity）以及 epidermal–dermal adherence 不良有關。p.971
  • Type VII collagen α chain 分子量 290 kDa；collagen 為 3 條相同 α chain 組成的 homotrimer。每條 α chain：胺基端有大型球狀 NC-1 domain（約佔 α chain 整體質量的一半）→ 中段 helical domain（glycine-X-Y repeats）→ 羧基端較小的球狀 NC-2 domain。p.972
  • 多數 EBA autoantibodies 辨認 NC-1 domain 內的 4 個主要 antigenic epitopes，不辨認 helical 或 NC-2 domain；現有針對 Type VII collagen 的 monoclonal antibodies 也只辨認 NC-1 subdomains。p.972
  • EBA 病人 lesional 與 perilesional skin 的 anchoring fibrils 數量減少，但造成減少的途徑不明；可能是新合成、被 EBA autoantibodies 結合的 α chains 無法形成 triple-helical structures 與穩定的 anchoring fibrils。p.972
  • 間接證據：以 cultured keratinocyte sheets 覆蓋的 healed burn wounds，在移植後第一年內 anchoring fibrils 數量減少，並伴隨自發性水疱、suction blistering time 縮短與 skin fragility，顯示 anchoring fibrils 與維持 epidermis–dermis 黏附有關。p.972

Autoantibodies 具致病性的證據

  1. Bullous SLE 這個「experiment of nature」：SLE 病人產生 Type VII collagen autoantibodies 時會出現廣泛皮膚水疱，屬於罕見的 SLE 亞型，即 bullous SLE105-49 107-47。p.972
  2. Passive transfer：把兔子產生的 human Type VII collagen NC-1 domain 高力價抗血清注入 hairless immune-competent 小鼠，小鼠出現 subepidermal blisters、足部指甲脫落，血中有 NC-1 抗體，DEJ 有 anti–NC-1 IgG 與 murine complement 沉積；Sitaru 等以兔抗 mouse Type VII collagen NC-1 的 polyclonal antibodies 也誘發 subepidermal blisters。p.972
  3. 以 NC-1 column affinity-purify 的 human EBA autoantibodies 注入小鼠，小鼠出現類似人類 EBA 的臨床、組織、免疫與超微結構特徵。p.972

免疫反應

  • 病人血中與 DEJ 組織上的 EBA IgG 涵蓋 IgG 的 4 個 subclasses，尤其是 IgG1 與 IgG4。p.972
  • 循環中的 EBA autoantibodies 同時有 complement-binding 與 non–complement-binding 兩種族群；與 BP 比較，EBA 病人的 C3b（90% vs 33%）與 C5（90% vs 58%）出現率較高；這些研究提供證據，顯示多數（majority）EBA 病人在 DEJ 有 complement activation，且 EBA antibodies 是比 BP antibodies 更強的 C5 activators。p.972
  • Gammon 等的 in vitro 切片試驗（以 leukocytes 向 DEJ 的移動與聚集為 readout）也顯示：EBA immune complexes 產生的 complement activation 比 bullous pemphigoid immune complexes 更多。p.972
  • 主動誘發的小鼠 EBA 模型涉及 complement-fixing anti–Type VII collagen antibodies，且需要 T cells 才能誘發疾病。p.972
易錯EBA 的 IgG 涵蓋 IgG 的 4 個 subclasses，尤其是 IgG1 與 IgG4（p.972）。多數 EBA autoantibodies 辨認的是 NC-1 domain 的 epitopes，不是 helical 或 NC-2 domain（p.972）。

McKee 補充：

  • N 端 145-kDa NC1 domain 含 cartilage matrix protein subdomain、9 個 fibronectin III-like subdomains、collagen-binding von Willebrand factor A-like subdomain 與 cysteine/proline-rich subdomain，是大多數 EBA 病人 autoantibodies 辨認的 immunodominant region；NC2（34 kDa）與中央 collagenous domain 較少成為標的。對不同 epitopes 的免疫反應被認為可能與臨床表現的多樣性有關。McKee p.156
  • 致病性抗體常針對 NC1 的 cartilage matrix protein subdomain；部分 inflammatory EBA 的抗體則辨認 triple-helical collagenous domain。Type VII collagen 與 fibronectin 親和力高。McKee p.160
  • 部分研究顯示致病機轉至少部分（at least in part）與 complement activation（C5a）造成的 neutrophil 招募有關；「cell-free」mechanobullous 型的機轉了解很少，幾乎沒有 neutrophil chemotactic activity 的證據，推測可能是 autoantibody 破壞 type VII collagen 與 laminin-332 及 fibronectin 等 matrix proteins 的親和力，或影響 type VII collagen antiparallel dimer assembly 而使 anchoring fibril 形成減少。McKee p.160

4. Clinical Findings（臨床表現）

若病人有無法解釋的皮膚水疱，應做 3 項檢查：一處皮膚切片做 H&E histology；緊鄰病灶但外觀正常的皮膚再取一處切片做 DIF；抽血以 IIF 或 ELISA 檢測抗 BMZ 及（或）Type VII collagen 抗體。p.972

EBA 的共同點是對 Type VII（anchoring fibril）collagen 的 autoimmunity105-49，臨床至少有 5 種表現型；其中 classic 與 BP-like 是最常被報告的。p.973

各表現型的比例

  • 依作者經驗，約 25% 的 EBA 病人可能呈現 BP-like 臨床表現112-46；其中部分病人最終會漸漸變成 non-inflammatory 的 mechanobullous 型；classic 與 BP-like 也可能同時存在於同一位病人（Fig. 56-5）。p.975
  • 像 pure cicatricial pemphigoid（CP）的表型佔所有 EBA 病例 <10%。p.975
  • Childhood EBA 罕見，表現多樣（LABD-like、BP-like 或 classic mechanobullous）；黏膜侵犯常見且嚴重，但整體 prognosis 比成人 EBA 好。p.975

Classic 型的其他表現

  • 部分水疱可能是 hemorrhagic，或出現 scales、crusts、erosions；癒合時留下 scarring，並常在疤痕內形成珍珠狀 milia cysts。p.974
  • 雖然可能像 PCT，但沒有 PCT 的其他 hallmarks：沒有 hirsutism、photodistribution 或 scleroderma-like changes，urinary porphyrins 在正常範圍內。p.974
  • 可能（may）可見 scarring alopecia 與某種程度的 nail dystrophy。p.974
  • 通常不像遺傳性 recessive dystrophic EB 那麼嚴重，但 classic 型 EBA 可能出現許多相同後遺症：scarring、掉髮、掉指甲、hands and fingers 的 fibrosis、esophageal stenosis。p.974

Related physical findings（相關理學表現）

  • EBA 病人可能（may）有許多與 Type VII collagen gene 缺陷造成的遺傳性 dystrophic EB 相似的理學表現：oral erosions、esophageal strictures、hypo- 與 hyperpigmentation 造成的皮膚斑駁、nail loss、milia formation、scarring，以及手部某種程度的 fibrosis。p.975–976

相關系統性疾病

  • 已有報告顯示 EBA 可能與多種系統性疾病相關：inflammatory bowel disease、SLE、amyloidosis、thyroiditis、multiple endocrinopathy syndrome、rheumatoid arthritis、pulmonary fibrosis、chronic lymphocytic leukemia、thymoma、diabetes、multiple myeloma，以及其他可能有 autoimmune pathogenesis 的疾病。p.976
  • University of North Carolina、Stanford、Northwestern 與 University of Southern California 合計追蹤超過 62 位 EBA 病人，經驗顯示 inflammatory bowel disease 似乎是與 EBA 最常相關的系統性疾病108-28 115-16。p.976
易錯Classic EBA 是 noninflammatory、發生在 noninflamed skin 的 mechanobullous disease（p.973–974）；BP-like 型則是 inflammatory、常有 pruritus，且不明顯有 skin fragility、scarring 或 milia（p.974）。作者經驗中約 25% 的病人可能呈現 BP-like，classic 與 BP-like 是最常被報告的兩型（p.973、p.975）。

McKee 補充：

  • EBA 最初被描述為像 porphyria cutanea tarda 的 mechanobullous dermatosis，後來也有廣泛 inflammatory bullous dermatosis 的病例。McKee p.156
  • Roenigk 於 1971 年的定義：類似 dystrophic EB 的病灶（手、腳、肘、膝輕微外傷後起水疱，並有 atrophic scarring、milia、nail dystrophy）、成年發病、EB 家族史陰性、排除其他 bullous dermatoses（包括 PCT、BP、DH、pemphigus、erythema multiforme、bullous drug reactions）。McKee p.156
  • 最重要的相關系統性疾病是 inflammatory bowel disease 與 diabetes mellitus；約 30% 的 EBA 病人有 IBD（以 Crohn disease 為主），控制 IBD 在部分病人可改善皮膚病灶；IBD 通常早於 EBA 出現。多達 68% 的 IBD 病人有抗 collagen type VII 抗體，但只有極少數發展成 EBA。另有 celiac disease 的相關報告，也偶見以 paraneoplastic phenomenon 表現。McKee p.157
  • MMP-like 型常侵犯口腔（舌、牙齦、上顎、頰黏膜），少見喉與食道 stricture；conjunctival lesions 是重要但不常見（infrequent）的 morbidity 原因，可能出現 symblepharon、epiphora 甚至失明。Brunsting-Perry 型中有些病人有 type VII collagen 抗體，可能更適合歸入 EBA spectrum。McKee p.157
  • IgA-EBA（linear IgA disease-like）：成人與兒童病人都有針對 type VII collagen 的 IgA autoantibodies；成人眼部侵犯常嚴重，失明並不罕見。McKee p.157

5. Bullous SLE（水疱型紅斑性狼瘡）

Fitzpatrick 在 EBA 章把 bullous SLE 視為 SLE 病人產生 Type VII collagen autoantibodies 而出現廣泛皮膚水疱的罕見亞型105-49 107-47；Fitzpatrick ch61 把 bullous SLE 列為 LE-nonspecific skin lesion107-47。p.972p.1037（ch61）

  • Bullous SLE 的 autoantibodies 與 EBA 相同，辨認 Type VII collagen 的 NC-1 domain105-49 107-47（Western blot 的 145-kDa band，含 EBA autoantibodies、bullous SLE autoantibodies 與 monoclonal antibodies 的 antigenic epitopes）。p.977
  • Chen 等開發的 recombinant NC-1 ELISA 可用於偵測 EBA 與 bullous SLE 病人的 autoantibodies。p.977
  • Salt-split skin IIF 若抗體標到 dermal side，病人通常是 EBA 或 bullous SLE；後者可用其他血清學檢查與臨床標準排除。p.977
  • Table 56-1 把 bullous SLE 列在 EBA 鑑別診斷的 “Consider”。p.978
  • HLA-DR2 phenotype 在美國東南部罹患 EBA 或 bullous SLE 的 African American 病人中比例高。p.971

6. Laboratory Tests（實驗室檢查）

Histopathology（組織病理）

  • Lesional skin 的 H&E：subepidermal blister，epidermis 與 dermis 之間 clean separation。真皮發炎細胞浸潤的程度通常反映臨床發炎程度。p.976
  • 像 recessive dystrophic EB 或 PCT 的病灶，真皮內發炎細胞通常（usually）明顯稀少；像 BP 的病灶通常有明顯較多發炎細胞，可混合 lymphocytes、monocytes、neutrophils 與 eosinophils；BP-like 病灶的組織學可能很難與 BP 本身區分。p.976

McKee 補充：

  • Mechanobullous 型：bland、“cell-free” subepidermal vesicle，只含少量紅血球與一點 fibrin；水疱腔內與鄰近或下方真皮通常沒有明顯發炎細胞浸潤（但有時可有少量 neutrophils、histiocytes、eosinophils）；basement membrane 位於水疱 roof；鄰近真皮常見明顯 scarring，也常見 milia。McKee p.157
  • Inflammatory 型：subepidermal vesicle 加上 lymphocytes、histiocytes、突出的 neutrophils 與 eosinophils 的混合浸潤；通常以 neutrophils 為主，初期病灶可見 neutrophils 沿 DEJ 呈線狀排列，偶以 eosinophils 為主；可像 BP 或 DH。McKee p.157
  • Paraffin 切片的 direct immunoperoxidase：type IV collagen 位於水疱 roof。EM：分離位置在淺層真皮、緊鄰 lamina densa 之下；basal keratinocytes 正常；anchoring fibrils 被報告為減少或消失。偶見電子緻密的無定形顆粒物質（位於 roof 內）。McKee p.158
  • 自溶（autolysis）造成的 dermal–epidermal 分離不要和 in vivo 水疱混淆：autolysis 的上皮典型（typically）呈明顯嗜酸性，細胞核常消失。McKee p.160

Direct immunofluorescence（DIF）

  • EBA 病人皮膚的 DEJ 有 IgG deposits，最適合取 perilesional 切片檢測；IgG 是主要的 immunoglobulin class，也可能偵測到 complement、IgA、IgM、factor B 與 properdin；DIF 呈 DEJ 上強烈的 linear fluorescent band。p.976
  • Yaoita 等認為 DIF 陽性且 IgG deposits 位於 sublamina densa zone 是診斷 EBA 的必要條件。p.976
  • PCT 的 DEJ 常也有 IgG 與 complement deposits，與 EBA 相似；能區分 PCT 與 EBA 的 DIF 特徵是 PCT 皮膚的 真皮血管周圍 也有免疫沉積。p.976

McKee 補充：絕大多數 EBA 在基底膜區有線狀 IgG 與 C3（與 BP 相同）；IgG 而無 C3 的沉積在 EBA 比 BP 常見；IgM、IgA、properdin、factor B 較少見；linear IgA disease-like 病人可只有 IgA 而無 IgG。另有 serrated pattern：‘u-serrated’ 為 EBA 與 SLE 的典型，‘n-serrated’ 一般（generally）見於 BP、MMP、linear IgA disease 等其他 subepithelial autoimmune blistering diseases。McKee p.158

Indirect immunofluorescence（IIF）

  • EBA 病人血中可能（may）有針對 DEJ 的 autoantibodies；以病人血清在 monkey 或 rabbit esophagus 或 human skin 上檢測，DEJ 呈 linear 染色，可能與 BP 血清無法區分。p.976

McKee 補充：IgG 抗基底膜抗體（antibasement membrane antibodies）可在 25–50% 的病人檢出，使其更類似 BP；EBA 的 IgG 多為 IgG1 與 IgG4 subclass；許多病人的抗體具 complement-fixing 性質。McKee p.158

Immunoelectron microscopy（IEM）

  • EBA 病人 DEJ 免疫沉積在 IEM 上的位置是診斷的 gold standard：免疫沉積位於皮膚 BMZ 的 sublamina densa zone。p.976
  • 此位置明顯不同於 BP（在較上方的 hemidesmosome 或 lamina lucida 區），也不同於 CP（抗原標的局限在 lamina lucida）。p.976–977
  • McKee：免疫反應物位於 lamina densa 上或其下；immunogold 顯示免疫球蛋白與 anchoring fibrils 有關。McKee p.159

Salt-split skin immunofluorescence

  • 人類皮膚在 1 molar NaCl 中孵育後，DEJ 會乾淨地斷在 lamina lucida：BP antigen 在 epidermal side（roof），其他所有 basement membrane 結構在 dermal side（floor）。p.977
  • Indirect salt-split IIF：血清 IgG 標到 epidermal roof，則病人不是 EBA，應考慮 BP；若標到 dermal side，病人通常是 EBA 或 bullous SLE。p.977
  • Direct salt-split IF：perilesional skin 在冷的 1 M NaCl 中孵育後從 DEJ 斷開，EBA 的 IgG 沉積留在 dermal floor，以一般 DIF 方法（FITC 標記 anti-human IgG）即可偵測；BP 的沉積則留在 epidermal roof112-46。Fig. 56-7 的標本在 1 molar 冷 saline 中孵育 72 小時。p.977

Western immunoblotting 與 ELISA

  • EBA 血清與人類皮膚 BMZ 蛋白的 Western blot 會結合 290-kDa band（Type VII collagen 的 α chain），其他所有 primary blistering diseases 的血清都不會；常有第二條 145-kDa band，為胺基端球狀 NC-1 domain（含豐富 carbohydrate，含 EBA autoantibodies、bullous SLE autoantibodies 與 monoclonal antibodies 的抗原 epitopes）。p.977
  • ELISA：Chen 等以穩定轉染人類細胞製得 recombinant、純化、經 posttranslational modification 的 NC-1，建立 ELISA；比 immunofluorescence 與 Western blotting 更靈敏，且對 Type VII collagen 抗體非常特異；已有商品化 ELISA。p.977
  • McKee：ELISA 可作為額外診斷檢查，並可用來監測疾病活動度。McKee p.159
易錯Salt-split 後 BP antigen 在 epidermal roof，EBA 的 Type VII collagen 在 dermal floor（p.977）。Salt-split IIF 若 IgG 標到 epidermal roof，應考慮 BP 而非 EBA（p.977）。IEM 免疫沉積在 sublamina densa zone，BP 在較上方的 hemidesmosome／lamina lucida 區（p.976）。

9. Complications（併發症）

  • Secondary skin infections（通常由 Staphylococcus 或 Streptococcus 引起），因為水疱與糜爛破壞皮膚屏障。p.978
  • Scarring 與 milia formation 是深層水疱過程自然產生的併發症或後遺症。p.978
  • 重症病人手部可能有明顯 fibrosis，使手掌與手指 range of motion 減少；足底與趾的傷口與 fibrosis 使部分病人行走困難；許多病人會掉指甲。p.978
  • 有明顯黏膜侵犯的病人可能出現 esophageal strictures，甚至 laryngeal scarring。p.978

10. Treatment（治療）

EBA 通常對治療反應不佳。所有病人都需要 supportive therapy。p.978

Supportive care（支持性治療）

  • 教導 open wound care 與避免外傷；不要過度清洗、不要使用熱水或刺激性肥皂，避免用毛巾長時間或用力摩擦皮膚。p.978
  • 部分病人長時間日曬似乎會加重或誘發手背與 knuckles 的新病灶，因此避免長時間日曬與使用防曬有幫助（helpful）。p.978
  • 教育病人辨識局部皮膚感染，並盡快就醫、接受抗生素治療。p.978

Systemic therapy（系統性治療）

  • EBA 病人常對高劑量 systemic glucocorticoids、azathioprine、methotrexate 與 cyclophosphamide 有 refractory 的反應，尤其是 classic mechanobullous 型108-28；這些藥物在 inflammatory BP-like 型可能有些幫助。p.978
  • 部分 EBA 病人對 dapsone 有改善，尤其是真皮浸潤中有 neutrophils 時。p.978
  • Cyclosporine 已被證實有效，但長期毒性限制使用。p.978
  • Colchicine：有獨立報告顯示高劑量有效；因副作用相對溫和，常被作為 first-line drug。但 diarrhea 是常見副作用，使許多病人難以達到足夠劑量；有 inflammatory bowel disease 的 EBA 病人作者對使用 colchicine 較猶豫；也有病人對 colchicine 無反應。Colchicine 是 microtubule inhibitor，但也似乎有可能抑制對 T cells 的 antigen presentation 的特性。p.978
  • Photopheresis 可改善臨床表現並明顯延長 suction blistering time，提示 dermal–epidermal adherence 改善。p.978
  • Plasmapheresis（移除血漿中的 anti–Type VII collagen 抗體）對控制 EBA 有用，如同 pemphigus 病人；進行時必須同時合併 chemotherapy agent（如 azathioprine、cyclophosphamide、mycophenolate mofetil、methotrexate；原文拼寫為 mycotile mofelate）。p.978
  • IVIG 曾有報告有效，作用機轉不明。p.978
  • Anti–TNF-α biologics（如 infliximab）在 uncontrolled open trials 中有些成功；Rituximab（anti-CD20）使病人 B 細胞明顯減少，對 recalcitrant EBA 有療效。p.978–979

115 年第 16 題Ch.53Ch.54Ch.56Ch.59

關於水皰病患者的系統性共病與死因的敘述，下列何者正確？

  • ①Paraneoplastic pemphigus 主要致死併發症為bronchiolitis obliterans。
  • ②失智、中風、帕金森氏症等神經疾病患者，發生Bullous pemphigoid風險顯著升高。
  • ③Epidermolysis bullosa acquisita 與很多系統性疾病有關，其中與Inflammatory bowel disease最相關。
  • ④Dermatitis herpetiformis患者的淋巴瘤風險會增加，但嚴格無麩質飲食對預防淋巴瘤並無助益。
選項

官方答案：C

①②③正確，答案 C。

  • ①正確PNP 死亡率高，死因包括 sepsis、治療併發症與 bronchiolitis obliterans；呼吸衰竭是常見的終末事件，進展為 bronchiolitis obliterans 在多數個案是致命的終末併發症。McKee 也寫 bronchiolitis obliterans-like disorder 見於 6–29% 病人且必定致命，ch11 稱其常為主要死因。Fitzpatrick 9e ch.53 p.934；Fitzpatrick 9e ch.53 p.941；McKee 5e p.184；McKee 5e p.440
  • ②正確近年研究顯示有 dementia、stroke、Parkinson disease 等神經疾病的病人，發生 bullous pemphigoid 的風險顯著較高。Fitzpatrick 9e ch.54 p.948
  • ③正確EBA 被報告與 IBD、SLE、amyloidosis、thyroiditis、RA、CLL、thymoma、diabetes 等多種系統性疾病相關，多中心經驗顯示 inflammatory bowel disease 是最常合併的系統性疾病。McKee 指出 EBA 最重要的相關系統性疾病是 IBD 與 diabetes mellitus，約 30% EBA 病人有 IBD（以 Crohn disease 為主）。Fitzpatrick 9e ch.56 p.971；Fitzpatrick 9e ch.56 p.976；McKee 5e p.157
  • ④錯誤DH 病人 non-Hodgkin lymphoma 風險確實增加，但回溯研究顯示無麩質飲食對 GI lymphoma 有保護作用，發生 lymphoma 的病人對無麩質飲食的遵從度較差，所以並非「無助益」。Fitzpatrick 9e ch.59 p.1003-1004
113 年第 38 題Ch.15Ch.52Ch.53Ch.57Ch.48Ch.60Ch.56

關於各種autoimmune/genetic diseases其所對應的epidermal and dermal protein targets，下列敘述何者正確？

  • ①Desmoglein可能為pemphigus vulgaris, IgA pemphigus及striate palmoplantar keratoderma的主要target之一。
  • ②Desmoplakin I/II可能為paraneoplastic pemphigus, diffuse palmoplantar keratoderma及skin fragility–wooly hair syndrome的主要target之一。
  • ③Keratin 5 及keratin14為epidermolysis bullosa simplex的主要target之一。
  • ④Desmocollin 1為epidermolysis bullosa acquisita的主要target之一。
選項

官方答案：C

①②③正確，答案 C。

  • ①正確Desmoglein 3（及 Dsg1）為 pemphigus vulgaris 的標的；Dsg1 與 Dsg3 都可在 IgA pemphigus（intraepidermal neutrophilic-type）被標的；Dsg1 haploinsufficiency 造成 striate PPK。McKee Table 5.1：pemphigus vulgaris 抗原為 Dsg3（黏膜）、Dsg1（皮膚），IgA pemphigus 為 Dsc1、Dsg1 或 Dsg3；SPPK type 1 為 DSG1 突變。Fitzpatrick 9e ch.15 p.235-236；McKee 5e p.172；McKee 5e p.187；McKee 5e p.97
  • ②正確Desmoplakin I/II 是 paraneoplastic pemphigus 的自體抗原；遺傳上 Carvajal syndrome（AR）有 diffuse PPK，skin fragility–wooly hair syndrome（AR）亦為 desmoplakin 突變。McKee 列 paraneoplastic pemphigus 抗原含 desmoplakins I and II，Carvajal-Huerta syndrome（DSP）表現為 PPK 合併 wooly hair。Fitzpatrick 9e ch.15 p.236；Fitzpatrick 9e ch.15 p.237；McKee 5e p.172；McKee 5e p.87
  • ③正確Keratin 5 與 14 是 epidermolysis bullosa simplex 的遺傳標的（Table 15-5）。McKee：EB simplex 是最早描述的 keratin 疾病，由 K5 或 K14 突變造成。Fitzpatrick 9e ch.15 p.244；Fitzpatrick 9e ch.5 p.64；McKee 5e p.5；McKee 5e p.121
  • ④錯誤Desmocollin 1 是 subcorneal pustular dermatosis-type IgA pemphigus 的自體抗原；EBA 的標的是 collagen VII（anchoring fibril）。McKee：SPD 型 IgA pemphigus 對 desmocollin 1 反應；EBA 的致病抗體針對 type VII collagen。Fitzpatrick 9e ch.15 p.236；Fitzpatrick 9e ch.15 p.244；McKee 5e p.187；McKee 5e p.160
112 年第 46 題Ch.59Ch.53Ch.54Ch.56

關於自體免疫水疱病，下列敘述何者正確？

  • ①Dermatitis herpetiformis大多很癢，以dapsone治療很快就會見效，可當成therapeutic diagnosis。
  • ②Paraneoplastic pemphigus常有口腔潰瘍，且大多有anti-desmogleins抗體，同時要注意有無Castleman disease或lymphoma。
  • ③可能導致bullous pemphigoid的藥物，包括furosemide, penicillin, ACE inhibitor等。
  • ④Epidermolysis bullosa acquisita (EBA)，一般是發炎的水泡，在肢端為多，經常有scar及milium formation，salt-split skin DIF是在dermal floor的部份會有IgG deposition。
選項

官方答案：C

①②③正確，答案 C。

  • ①正確DH 大多極癢，dapsone 可在數小時至數天內迅速改善，停藥後數小時至數天內惡化；這種治療反應過去長期是診斷最重要的依據（therapeutic diagnosis）。McKee 亦寫 dapsone 反應極佳（數小時內止癢），因此常兼作診斷與治療用途。Fitzpatrick 9e ch.59 p.1002；Fitzpatrick 9e ch.59 p.1007；McKee 5e p.163
  • ②正確PNP 幾乎都有頑固性口腔潰瘍，且幾乎所有病人都有 anti-desmoglein 抗體；最常合併的腫瘤是 NHL、CLL 與 Castleman disease，需積極尋找。McKee 指出 PNP 通常有 Dsg1 與 Dsg3 抗體，並列出 Castleman disease 與 B-cell lymphoproliferative disorders 等相關腫瘤。Fitzpatrick 9e ch.53 p.934-935；McKee 5e p.184；McKee 5e p.185
  • ③正確可誘發 bullous pemphigoid 的藥物包括 diuretics（furosemide、spironolactone）、ACE inhibitors 與抗生素（penicillins、fluoroquinolones）等。McKee 列出 penicillins、furosemide，以及 captopril、enalapril 等 ACE inhibitors 為藥物誘發 BP 的藥物。Fitzpatrick 9e ch.45 p.753；Fitzpatrick 9e ch.54 p.946；McKee 5e p.653
  • ④錯誤後半正確（acral、trauma-prone 部位，留疤與 milia，salt-split skin 上 IgG 在 dermal floor），但 classic EBA 是「非發炎性」的 mechanobullous disease，水疱長在未發炎的皮膚上；發炎型（BP-like）約只占 25%，所以「一般是發炎的水泡」錯誤。McKee 也寫 classical（mechanobullous）型是最常見的 EBA，水疱特徵為 noninflammatory，split skin 上免疫反應物位於底部。Fitzpatrick 9e ch.56 p.973-975；Fitzpatrick 9e ch.56 p.977；McKee 5e p.156；McKee 5e p.158
108 年第 28 題Ch.105Ch.54Ch.56

關於autoimmune bullous disease，下列敘述何者錯誤？

  • ①Pemphigoid gestationis患者的致病機轉主要是體內產生抗BP230的抗體，且測得此抗體的titer通常比類天疱瘡患者還高。
  • ②Epidermolysis bullosa acquisita (EBA)可能與inflammatory bowel diseases (IBD)相關。
  • ③Pemphigoid gestationis大都發生於懷孕晚期，且大都在分娩時有顯著的改善。
  • ④Epidermolysis bullosa acquisita (EBA)患者常常對systemic glucocorticoids的反應不佳。
選項

官方答案：A

①③ 錯誤，答案 A。

  • ①錯誤Pemphigoid gestationis 的自體抗體與 bullous pemphigoid 針對相同抗原，但較常針對 BP180 而非 BP230；ELISA 檢測的是 BP180。McKee 指出致病抗體針對 BP180 的 NC16A domain，抗 BP230 抗體只見於 10–26% 的病例；所謂 HG factor 只是 low titer 的 complement-fixing IgG anti-BMZ antibody，並非 titer 比 bullous pemphigoid 高。Fitzpatrick 9e ch.105 p.1767；Fitzpatrick 9e ch.54 p.947；McKee 5e p.148
  • ②正確EBA 曾被報告與多種系統性疾病相關，其中 inflammatory bowel disease 是最常合併的系統性疾病。Fitzpatrick 9e ch.56 p.976
  • ③錯誤PG 好發於第二或第三孕期，但 75% 的患者在產後發作加劇（flare postpartum）而需要治療，並非大都在分娩時顯著改善。Fitzpatrick 9e ch.105 p.1767
  • ④正確EBA 患者常對高劑量 systemic glucocorticoids、azathioprine、methotrexate、cyclophosphamide 反應不佳，尤其是 classic mechanobullous form。Fitzpatrick 9e ch.56 p.978

附註① 後半「PG 抗體 titer 通常比類天疱瘡高」Fitzpatrick 未提及，依 McKee p.148（HG factor 為 low titer 抗體）判定為錯。

107 年第 47 題Ch.56Ch.61

關於bullous systemic lupus erythematosus，下列敘述何者正確？

  • ①可發生於sun-exposed and nonsun-exposed skin。
  • ②DIF有可能呈現granular pattern或是linear pattern。
  • ③可能會合併有白血球細胞破裂性血管炎(leukocytoclastic vasculitis)。
  • ④病理下常見到lymphocyte-rich subepidermal vesicle。
選項

官方答案：C

①②③正確，答案 C。

  • ①正確Bullous SLE 屬 LE-nonspecific 皮膚病灶，是 SLE 病人產生抗 Type VII collagen 抗體所致的廣泛性水疱。Fitzpatrick 未明列分布，McKee 寫水疱以曝光處為主，但非曝光處與口腔、咽部黏膜也常受侵犯。Fitzpatrick 9e ch.61 p.1037；Fitzpatrick 9e ch.56 p.972；McKee 5e p.161
  • ②正確Bullous SLE 的自體抗體針對 Type VII collagen NC-1 domain，在 salt-split skin 上結合真皮側，與 EBA 相同；McKee 寫 DIF 在基底膜區有免疫球蛋白與補體沉積，granular 約 40%、linear 約 60%。Fitzpatrick 9e ch.56 p.977；Fitzpatrick 9e ch.15 p.246；McKee 5e p.162；McKee 5e p.163
  • ③正確Bullous SLE 屬嗜中性球主導的表皮下水疱，可合併 leukocytoclastic vasculitis；SLE 本身的 LE-nonspecific 病灶也包括 leukocytoclastic vasculitis。McKee 也寫 bullous SLE 有時同時出現 leukocytoclastic vasculitis 的特徵。Fitzpatrick 9e ch.61 p.1038；McKee 5e p.162
  • ④錯誤Bullous SLE 病理為 neutrophil-rich 的表皮下水疱，乳頭真皮嗜中性球聚集，早期病灶可與 DH、linear IgA disease 難以區分，不是 lymphocyte-rich。McKee 描述水疱腔內為 fibrin、大量 neutrophils 與 karyorrhectic debris，旁邊皮膚有 subepidermal neutrophil microabscesses，lymphocytes 只偶見。Fitzpatrick 9e ch.59 p.1006；McKee 5e p.161

附註Fitzpatrick 9e 未獨立描述 bullous SLE 的分布、DIF 型態與病理，①②③④依 McKee p.161–162。

105 年第 49 題Ch.60Ch.56Ch.15

下列何者水泡病的致病機轉與anchoring fibril proteins中的collagen VII較不相關？

選項

官方答案：B

Herlitz JEB 與 collagen VII 無關，答案 B。

  • A與 collagen VII 相關Bullous SLE 是 SLE 病人產生針對 Type VII collagen NC-1 domain 的自體抗體所致。McKee 寫 bullous SLE 抗體與 EBA 相同，針對 type VII collagen 的 NC1 與 NC2 domain。Fitzpatrick 9e ch.56 p.972；Fitzpatrick 9e ch.15 p.246；McKee 5e p.163
  • B本題答案Herlitz（generalized severe）JEB 是 laminin-332（LAMA3、LAMB3、LAMC2）null mutation 造成，分離在 lamina lucida，與 anchoring fibril 的 collagen VII 無關。McKee 亦寫 laminin-332（LAMA3、LAMB3、LAMC2）突變造成 generalized severe（以前稱 Herlitz）JEB，分離在 lamina lucida。Fitzpatrick 9e ch.60 p.1015；Fitzpatrick 9e ch.60 p.1020；McKee 5e p.133
  • C與 collagen VII 相關Dominant 與 recessive DEB 都源自 COL7A1 突變，造成 anchoring fibril 缺陷與 sublamina densa 分離。McKee 指出 COL7A1 突變是顯性與隱性 DEB 的共同原因，DDEB 多為 triple helix 的 heterozygous missense mutation。Fitzpatrick 9e ch.60 p.1021；Fitzpatrick 9e ch.15 p.246；McKee 5e p.133
  • D與 collagen VII 相關EBA 的共同特徵就是對 Type VII（anchoring fibril）collagen 的自體免疫。McKee 寫 EBA 的標的抗原是 type VII collagen（290 kD），以 NC1 domain 為主要抗原區。Fitzpatrick 9e ch.56 p.973；McKee 5e p.156
