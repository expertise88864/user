1. Innate vs Adaptive Immune System（先天與後天免疫）

  • Skin immune system 同時含 innate 與 adaptive 成分：由大量 skin-resident immune cells，加上在 skin、skin-draining lymph nodes 與 peripheral circulation 之間不斷 recirculate 的 lymphocytes 組成；keratinocytes、endothelial cells、fibroblasts 等 parenchymal cells 也常參與（often involve）。p.143
  • Innate：辨識與廣泛類別病原相關的 motifs（proteins、lipids、nucleotides、metabolites），受體由 germline DNA 編碼；功能是快速的第一線防禦，並促進 adaptive response、決定其類型。p.143
  • Adaptive：靠 somatic recombination 產生近乎無限的 antigen receptor／antibody 多樣性，並形成 immunologic memory（long-lived antigen-specific lymphocytes）；反應較慢但更強大。p.143
  • T cells 與 B cells 是 adaptive immune system 的主要細胞103-03；dendritic cells 與 macrophages（顯著表現 pattern-associated receptors，原文用字）是 innate immune system 的關鍵細胞。其他參與 innate response 的有 mast cells、neutrophils，以及 keratinocytes、endothelial cells、fibroblasts 等 resident tissue cells。p.143
  • AT-A-GLANCE：innate 的各細胞次群共同點是對感染與損傷反應快，但辨識與回應所有病原的能力有限，靠 germline-encoded pattern recognition receptors 與 danger signals；adaptive 較慢但能回應近乎無限範圍的病原；ILCs 與 unconventional T cells 橫跨 innate 與 adaptive。兩個系統協同防禦，但異常活化可能經常（can frequently）導致各種發炎疾病。p.143, 145
  • 兼具 innate 與 adaptive 特性的細胞：innate lymphoid cells（ILCs）與 innate-like T cells（Fig. 11-2）。p.143–144
  • Trained immunity：innate immune system 對反覆挑戰的「記憶」反應，不依賴 T、B cells 即可保護避免再感染。p.143

2. T Cells and Subsets（T 細胞與次群）

  • T cells 來自骨髓的 multipotent hematopoietic stem cells，在 thymus 成熟（T = thymus-dependent）。多數是 αβ T cells；少數是 γδ T cells（limited diversity，被視為 innate immune system 的一部分）。p.145
  • Naïve T cells：已完成 thymus 發育、尚未遇到特定 antigen，循環於血液與 secondary lymphoid organs（lymph nodes、spleen）。遇到 antigen-presenting cell 上的 peptide–MHC complex 後，發育成 effector T cells 與較長壽的 central memory T cells。p.145
  • CD8+：辨識 MHC class I（HLA-A、-B、-C）上的 peptide，分化為 cytotoxic effector T cells；effector 常（often）依主要 cytokine 稱 TC1（IFN-γ）、TC2（IL-4）、TC17（IL-17）。部分 αβ CD8+ T cells 的 TCR diversity 有限，可經 CD1 等 MHC class I–like 分子辨識 lipid antigens。p.145
  • CD4+：辨識 MHC class II（HLA-DR、-DQ、-DP）上的 peptide，分化為 TH1、TH2、TH17、TFH 與 Tregs（Fig. 11-4）。p.145

3. Skin Homing（皮膚歸巢）

  • T cells 進入皮膚需表現 cutaneous lymphocyte antigen（CLA）與特定 chemokine receptors，包括 CCR4 與 CCR10。p.146–147
  • CLA 是 PSGL-1（P-selectin glycoprotein ligand-1）經 inducible carbohydrate modification 而成；PSGL-1 本身恆定表現於所有人類 peripheral-blood T cells。此修飾使其能結合 skin endothelial cells 高度表現的 E-selectin104-40。p.147
  • CCR4 結合 chemokines CCL17 與 CCL22；CCR10 結合 CCL27104-40。p.147
  • CCR4 存在於 essentially all skin-homing cells；CCR10 只在 skin-homing T cells 的一個 subset 上104-40。p.147
  • 這種專一的 T-cell trafficking，使發炎部位的 antigen-reactive T cells 比血液中濃縮 >100-fold。p.147
  • Keratinocytes 分泌的 CCL17、CCL22 吸引 TH2 cells；CCL20 吸引 TH17 cells；CXCL9、CXCL10 吸引 TH1 cells。p.157
  • Mast cell–derived TNF 可上調血管內皮的 E-selectin（即結合 CLA 者），促進 T cells 與 dendritic cells 湧入。p.154
易錯本章 p.147 把 CCR7／L-selectin（CD62L）列為 central memory markers，與 skin-homing receptor CLA、CCR4 並列；skin homing 的 chemokine receptors 本章寫的是 CCR4 與 CCR10。

4. TRM, TEM, TCM and TMM（組織常駐與循環記憶 T 細胞）

  • 健康人類皮膚約有血液全體 T cells 的 2 倍（約 20 billion）；skin-tropic（CLA+）memory T cells 在非發炎狀態下，98% 在皮膚、只有 2% 在循環中。p.147
  • Xenotransplant model：把 psoriasis 病人外觀正常的皮膚移植到 immunodeficient mice，數週後未受侵犯的皮膚自行長出 psoriasis；表示 noninflamed skin 內的 resident T cells 本身就足以造成發炎病變，不需 recirculating lymphocytes。p.147
  • TRM 是 nonrecirculating memory T cells，存在於 epithelial barrier tissues：GI tract、lung、skin、reproductive tract111-15。p.147
  • Vaccinia 經 skin scarification 接種，產生較多 skin-resident memory CD8+ cells，對皮膚再感染的保護比 subcutaneous、intradermal、intramuscular 接種有效 100,000 倍。p.147

5. B Cells（B 細胞）

  • B cells 是 humoral arm，產生 antibodies：中和病原（阻止其進入並感染細胞），也可能（may）中和 bacterial toxins、opsonization（促進 phagocytes 經 Fc receptor 攝取）、活化 classical complement pathway。p.148
  • B cells 離開骨髓後遷移到 spleen、peripheral lymph nodes、gut-associated lymphoid tissue；活化通常需要 TFH 幫助；活化後分化為 memory B cells 或 antibody-secreting plasma cells。p.148
  • TFH cytokines 決定 isotype：IL-4 促進 IgG1、IgG4、IgE；IFN-γ 誘導 IgG3；TGF-β 誘導 IgA。p.148
  • 正常皮膚中 B cells 很少，在皮膚免疫的角色仍不清楚；但在 cutaneous leishmaniasis、diffuse cutaneous sclerosis、cutaneous lupus、atopic dermatitis 等慢性發炎皮膚病可見 B cells；plasma cells 可見於 syphilis 與 leprosy。p.148–149
  • Bregs（IL-10 producing B cells）有抗發炎作用，但至今這些發現僅（only）在 murine models of skin inflammation 證實；近來已有在人類皮膚描述這些細胞的存在。p.149

6. ILCs and Unconventional T Cells（先天淋巴細胞與非典型 T 細胞）

這些是 nonrecirculating、位於 nonlymphoid tissues 的 lymphocytes，橫跨 innate 與 adaptive；被認為是組織完整性受損（感染、損傷）的 sensors，可招募血液中的免疫細胞並放大局部發炎。包括 iNKT、MAIT、γδ T cells、intestinal IELs 與 ILCs。p.149

7. Natural Killer（NK）Cells（自然殺手細胞）

  • NK cells 是 large granular lymphocytes；人類 NK cells 的標記是 CD16+ CD56+ CD94+ CD161+，且 CD3 陰性（不表現 T-cell marker）113-43。p.151
  • 功能是巡視全身，找出 altered cells（transformed，或被 virus／parasite 感染）；直接經 perforin／granzyme／granulysin 或 Fas／Fas-ligand 依賴機制殺死，或間接經分泌 cytokines。p.151
  • NK cells 最廣為人知的功能包括辨識並殺死被病毒感染的細胞與腫瘤細胞，以及分泌 IFN-γ（a main immunoregulatory cytokine）；而 pDCs 才是以 TLR7、TLR9 活化後大量產生 type I interferons（IFN-α、IFN-β）的細胞109-10。p.134（ch10）
  • 本章 p.143 把 T cells 與 B cells 列為 adaptive 的 primary cells；NK cells 在 p.151 另列一節。p.143, 151
  • 本章 p.151 寫 NK cells 經 perforin／granzyme／granulysin、Fas／Fas-ligand 或分泌 cytokines 殺傷；明確寫到大量產生 type 1 interferons 的細胞是 plasmacytoid dendritic cells（見下一節，約為其他細胞的 10,000-fold）109-10。p.151–152

8. Dendritic Cells（樹突細胞）

  • DCs 的主要功能是處理 antigen、呈現於細胞表面並活化 T cells；主要來自骨髓 myeloid progenitors。Ralph Steinman 因發現其在 adaptive immune response 的核心角色獲 Nobel Prize。p.151
  • 本章列出健康皮膚的 3 種 cutaneous DC populations：epidermal Langerhans cells、resident dermal conventional DCs、plasmacytoid DCs109-14；發炎時另有 myeloid dermal「inflammatory」DCs。p.152
  • 未受擾動時 DCs 處於 immature state：能有效攝取 antigen，但 costimulatory molecules 低，不足以刺激 naïve T cells。p.152
  • 抗原處理：經 complement receptors 與 Fc receptors phagocytosis 攝入的 antigen 呈現在 MHC class II（給 CD4+ T cells）；直接進入 cytosol 的 antigen 經 proteasome → ER → MHC class I（給 naïve CD8+ T cells）。DCs 也擅長 cross-presentation（外來 antigen 經 MHC class I 呈現），對抗多種病毒與清除 autoreactive CD8+ T cells 重要。p.152

Inflammatory DCs（Tip-DCs）

  • Psoriasis 中的 inflammatory DCs 產生 TNF-α、表現 iNOS，稱 Tip-DCs；有效治療時 TNF-α、IL-20、IL-23 迅速下降；可刺激 Th17 cells 分化與活化。p.152

Plasmacytoid dendritic cells（pDCs）

  • 形態類似 plasma cells；被認為是對抗 viral infection 的早期 sentinels。p.152
  • 表現 TLR7 與 TLR9，以及 intracellular nucleic acid sensor RIG-1（對某些 single-stranded RNA viruses 的 pattern recognition receptor）113-43 109-10。p.152
  • 與 conventional DCs 相比，pDCs 表面的 MHC class II 與 costimulatory molecules 較少，處理 antigen 較不有效。p.152
  • 產生 type 1 interferons 的量估計比任何其他細胞多約 10,000-fold；主要誘導物是含重複 CG 的 viral RNA／DNA（CpG）結合 TLR7 與 TLR9109-10 113-43。p.152
  • Psoriasis：pDCs 被認為與 psoriasis 致病有關（implicated），似乎（appearing to）在觸發 psoriatic lesions 起始中扮演關鍵角色，機轉是 cathelicidin（LL37）與 self-DNA 結合後活化 TLR9。p.152
易錯本章 p.152 寫 pDCs 大量產生的是 type 1 interferons（約為其他細胞的 10,000-fold），沒有寫 IFN-γ；IFN-γ 在本章出現於 TH1 cells（p.145）、ILC1（p.149）與 M1 macrophage 活化（p.153）。

Langerhans cells（LCs）

  • 位於 epidermis 的 DC 特化亞群，由 Paul Langerhans 於 1868 描述（當時誤認為屬神經系統）；後來才認識到是 bone marrow 來源的 leukocytes。p.152
  • 占表皮細胞的 2% 到 4%，在 keratinocytes 之間排成 dense network113-43。p.152
  • 特徵性 organelle 是 electron-dense 的 Birbeck granules，形狀獨特如「tennis-racket」；高表現 CD1a113-43。p.152
  • CD207（langerin）：C-type lectin receptor，位於 Birbeck granules，可能把 antigen 導向 nonclassical processing pathway 而 cross-presentation 於 MHC class I；langerin 是 Birbeck granule 形成所必需113-43。p.152, 151
  • LCs 的發育與 epidermal residence 需要 keratinocyte 來源的 IL-34 與 TGF-β；LCs 的角色尚未完全清楚：可在 IL-15 依賴下 cross-prime CD8+ T cells，也參與（contribute to）Tregs 擴增，提示其在 tissue homeostasis 的角色。p.153
  • 抗原捕捉後 LCs 成熟並遷移到 regional lymph nodes 活化 T cells，T cells 再回到皮膚。p.151

McKee 補充（組織／電顯）

  • 電顯下 LCs 有 lobulated nucleus、相對清澈的細胞質、發達的 ER、Golgi 與 lysosomes；Birbeck granules 為 rod 或 racquet 形，屬 endosomal recycling compartment 的 subdomains，形成於 Langerin 聚集處。McKee p.11

  • LCs 可見於整個 epidermis，往上可到 granular layer；受刺激後離開 epidermis、經 lymphatics 到 regional lymph nodes，在 paracortical region 向 T lymphocyte 呈現 antigen。McKee p.11

10. Mast Cells（肥大細胞）

  • 通常（usually）最多見於 epithelial sites（skin、mucosa），是對外在病原與環境刺激的 first line of defense；源自 pluripotent bone marrow precursors，progenitors 經血液進入組織後才成熟。p.153
  • 成熟關鍵因子：stem cell factor（SCF，即 KIT ligand），結合 c-kit receptor（CD117），以及 IL-3。p.153
  • 壽命長（組織中可存活 months to years），保有增生能力。p.153
  • 組成性表現 FcεRI；最為人知（best-known）的活化原因是 antigen 交聯結合在 FcεRI 上的 IgE，所需 allergen 量相對少；也能經 FcγRII 結合 IgG。p.153
  • 也有 pattern recognition receptors（多種 TLRs）：TLR4 被 lipopolysaccharide 活化 → 產生 cytokines 但不 degranulation；TLR2 被 peptidoglycans 活化 → degranulation 與 cytokine 產生都有。其他活化因子：complement（C3a、C5a）、neuropeptide（substance P）、某些毒素（certain toxins）。p.153
  • 電子緻密的 lysosome-like secretory granules 佔成熟 mast cell 細胞質大部分；初期命名 "mastung"，意為 "well fed" 或 "fattened"。p.153
  • 顆粒內預先形成：histamine（可能是最著名者，probably the most well known）、serotonin、TNF-α、VEGF、proteases、抗菌蛋白 cathelicidins106-08、chemokines。活化後可再產生 TNF-α、IL-3、IL-4、IL-5、IL-6，以及 leukotrienes、prostaglandins、platelet-activating factor。p.154
  • 這些介質造成血管通透性上升與水腫，即數分鐘內發生的 wheal and flare；mast cell–derived TNF 可（can）上調血管內皮 E-selectin（結合 T cells 上的 CLA）等 adhesion molecules，加上 CCL20，促進 T cells 與 DCs 湧入。整體因含 IL-4 等 cytokines，反應偏向 TH2。p.154
  • 最常直接歸因於 mast cell 活化的皮膚反應：urticaria 與 anaphylaxis。p.154

11. Granulocytes（顆粒球）：Neutrophils, Eosinophils, Basophils

Basophils、neutrophils、eosinophils 屬 granulocytes：特徵是 lobulated nuclei 與細胞質 secretory granules（Table 11-3）。p.154

Neutrophils（嗜中性球）

  • 血液中最多的 leukocytes，占 peripheral blood leukocytes 約 35% 到 70%；短命，life span 約 5 到 90 小時113-43。p.154
  • 生成受 G-CSF 控制，最多可達 2 × 10¹¹ 個／天。p.155
  • Hallmark cell of acute inflammation；通常在數分鐘內被招募到損傷部位，主導對感染或組織損傷的 first wave of host defense109-10。p.155
  • 殺菌機制：phagocytosis、degranulation、reactive oxygen species（ROS，respiratory burst）、neutrophil extracellular traps（NETs）113-43。p.155
  • Neutrophil swarming：早期被招募的細胞（neutrophils、macrophages）訊號使更多 neutrophils 被指數式招募。p.155

Eosinophils（嗜酸性球）

  • Paul Ehrlich 於 1879 描述；因能被 acidophilic dyes（如 eosin）染色而得名。Eosin 是酸性染劑，結合含 arginine、lysine 殘基的 basic（eosinophilic）蛋白，染成深紅色107-11。p.156
  • 源自 bone marrow pluripotent progenitors，以成熟狀態釋出到血液；占 peripheral blood leukocytes 約 0 到 5%；以 bilobed nuclei 與大型 specific granules 與 neutrophils 區分。p.156
  • 顆粒含 4 種主要蛋白：eosinophil peroxidase、major basic protein，以及 ribonucleases eosinophil cationic protein 與 eosinophil-derived neurotoxin107-11；顆粒還儲存多種 cytokines、enzymes、growth factors。p.156
  • 招募：IL-5 與 eotaxin chemokines（CCL11、CCL13、CCL26）；表現 IL-5Rα 與 CCR3（結合 CCL11、CCL13、CCL26）。p.156
  • IL-5 對 eosinophil 發育的各方面都有重要作用，可由 T cells 與 mast cells 產生107-11；epithelial cell–derived cytokines TSLP（atopic dermatitis 常見）、IL-25（IL-17E）、IL-33 經誘導 IL-5 產生而促進 eosinophilia。p.156
  • 組織中的 eosinophils 通常（usually）靠近 mast cells，兩者大量溝通；其 crosstalk 被認為（thought to）涉及 physical 與多種 soluble mediators，調節 allergic inflammation。p.156

Basophils（嗜鹼性球）

  • 占 peripheral blood leukocytes <1%，是最少的 granulocyte。p.156
  • 與 mast cells 不同：basophils 在 bone marrow 完成成熟後才進血液；life span 為 several days（mast cells 為 weeks to years）；不保有增生能力。p.156

113 年第 43 題Ch.11Ch.10

關於皮膚免疫系統（cutaneous immune system），下列敘述何者正確？

  • ①Natural killer cells不表現T-cell markers CD3。
  • ②Plasmacytoid dendritic cells可藉由Toll-like receptors 7 and 9的表現來對抗病毒感染。
  • ③Langerhans cells大約佔了表皮細胞數量的2%到4%，在電子顯微鏡下可見到網球拍樣的Birbeck granules。
  • ④Neutrophils的生命週期長達7到10天，可藉由phagocytosis、degranulation或是釋放neutrophil extracellular traps（NETs）等機轉來清除致病原。
選項

官方答案：C

①②③正確，答案 C。

  • ①正確人類 NK cells 為 large granular lymphocytes，表現 CD16+ CD56+ CD94+ CD161+，但不表現 T-cell marker CD3。Fitzpatrick 9e ch.11 p.151
  • ②正確pDCs 表現 TLR7 與 TLR9（及 RIG-1 等 nucleic acid sensors），作為早期抗病毒防禦的 sentinels，可大量產生 type I interferons。Fitzpatrick 9e ch.11 p.152；Fitzpatrick 9e ch.10 p.134
  • ③正確Langerhans cells 約占表皮細胞的 2% 到 4%，特徵是 electron-dense、呈「tennis-racket」形狀的 Birbeck granules（含 langerin/CD207），並高度表現 CD1a。McKee 描述 Birbeck granules 為 rod 或 racquet 形，形成於 Langerin 聚集處。Fitzpatrick 9e ch.11 p.152；Fitzpatrick 9e ch.10 p.135；McKee 5e p.11

關於皮膚的先天免疫系統(innate immune system)，下列敘述何者錯誤？

  • ①大部分皮膚受損的情況下，第一個動員的白血球是嗜中性球(neutrophil)
  • ②NK細胞能辨識被病毒感染的細胞和腫瘤細胞並分泌干擾素interferon-α和interferon-β殺死這些細胞

109 年第 14 題Ch.10Ch.11

關於皮膚的後天性免疫系統(adaptive immune system)，下列敘述何者正確？

  • ①正常的人類皮膚主要有3類抗原呈現樹突狀細胞(antigen presenting dendritic cells):表皮的Langerhans cells、真皮的樹突狀細胞(dendritic cell)和CD141+的樹突狀細胞

官方答案：A

  • ④錯誤皮膚中絕大多數 T cells 表現 memory（CD45RO+）而非 naïve（CD45RA+）phenotype。Fitzpatrick 9e ch.10 p.136
