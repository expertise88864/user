兩種編輯模式：簡易站內編輯器（不需登入、立即可用）或 Decap CMS（需 GitHub OAuth、可直接 commit）。

推薦 · Word-style 編輯

📝 簡易站內編輯器（client-side）

純前端 WYSIWYG 編輯器、不需登入、不需 OAuth。支援 Ctrl+Z 復原 / Ctrl+Y 重做 / Ctrl+B 粗體 / Ctrl+K 連結 / Ctrl+S 存草稿。修改後可匯出 HTML 或複製內文、手動貼回 source。

  • localStorage 草稿暫存、瀏覽器關掉也不會掉
  • 「匯出 HTML」會下載完整修改後的檔案、覆蓋 source 即可
  • 適合快速試改 / 預覽 / typo 修正

→ 開啟簡易編輯器

✓ 立即可用、不需設定
進階 · Git-based CMS

⚙ Decap CMS（GitHub OAuth）

開源 git-based CMS、編輯後可直接 commit + push 到 GitHub、Vercel 自動部署。需要先在 Vercel 部署一個 OAuth proxy（/api/auth）才能登入。目前 OAuth proxy 尚未設定、登入會失敗。

  • 已配 /admin/config.yml（articles / glossary / config 三個 collection）
  • 需新增 GitHub OAuth App + 部署 /api/auth.js serverless function
  • 適合長期穩定的編輯流程

→ 開啟 Decap CMS

⚠ 需要先設定 GitHub OAuth proxy
