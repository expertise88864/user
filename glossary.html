量表機轉藥物分型檢查 / 處置症狀

1 · 臨床量表 / 評估工具

量表
SCORAD
Severity Scoring of Atopic Dermatitis
異位性皮膚炎嚴重度評分。面積 + 客觀症狀（紅、腫、滲、抓痕、苔癬化、乾）+ 主觀症狀（癢、失眠）三大項組合，0-103 分。<25 輕、25-50 中、>50 重。
SCORAD 計算器 →
量表
PASI
Psoriasis Area and Severity Index
乾癬嚴重度。頭頸 / 上肢 / 軀幹 / 下肢四區紅斑 + 浸潤 + 鱗屑 + 面積加權，0-72。健保生物製劑申請門檻 PASI ≥ 10。
PASI 計算器 →
量表
DLQI
Dermatology Life Quality Index
皮膚病生活品質量表,10 題自評，0-30 分。生物製劑健保申請常見門檻 DLQI ≥ 10。
DLQI 計算器 →
量表
UAS7
Urticaria Activity Score over 7 days
蕁麻疹活動度。每天「風團數」+「癢感」各 0-3，連續 7 天加總，0-42。控制目標 ≤ 6。
UAS7 計算器 →
量表
UCT
Urticaria Control Test
蕁麻疹控制測試，4 題快速評估。16 = 完全控制、12-15 = 部分控制、< 12 = 控制不佳。
蕁麻疹文章 →
量表
SALT
Severity of Alopecia Tool
圓禿頭皮禿髮百分比。頂(40%)+ 後(24%)+ 左(18%)+ 右(18%)。SALT ≥ 50 為重度，JAK 抑制劑適應症。
SALT 計算器 →
量表
GAGS
Global Acne Grading System
痘痘嚴重度全球分級。6 部位 × 病灶嚴重度權重總和，0-44。≥ 31 為重度，Isotretinoin 適應症。
GAGS 計算器 →
量表
MASI
Melasma Area & Severity Index
肝斑嚴重度。前額 + 兩頰 + 下巴 4 區的面積 × （深淺 + 同質性）加權，0-48。
MASI 計算器 →
量表
Hurley 分期
Hurley Staging (HS)
化膿性汗腺炎(HS)I 期 / II 期 / III 期分級。II 期以上為 Adalimumab 健保適應症參考。
Hurley 計算器 →
量表
Norwood-Hamilton / Ludwig
Male / Female Pattern Hair Loss Scale
男性 Norwood I-VII / 女性 Ludwig I-III 雄性禿分級。越嚴重需越積極治療(Finasteride、植髮）。
分級計算器 →
量表
Fitzpatrick 膚色
Fitzpatrick Skin Type
膚色分型 I-VI。亞洲人多為 III-IV 型，雷射 / 化學換膚易反黑(PIH)，需嚴格防曬。
Fitzpatrick 計算器 →
量表
EASI
Eczema Area & Severity Index
異膚另一常用評估，SCORAD 替代品。EASI 75 / 90 / 100 表示改善 ≥75% / 90% / 100%。
異膚文章 →
量表
IGA-PN
Investigator's Global Assessment for Prurigo Nodularis
結節性癢疹整體評估。0-4,0 = 清除、1 = 接近清除（治療目標）。
PN 文章 →
量表
WI-NRS
Worst Itch Numeric Rating Scale
過去 24 小時最強搔癢 0-10 分。≥ 4 分降幅為臨床顯著反應。
PN 文章 →
量表
VIDA
Vitiligo Disease Activity
白斑活動度評估。VIDA ≥ +2 為活動性，需口服治療壓制；VIDA ≤ 0 ≥ 1 年為穩定可手術。
白斑文章 →
量表
TNMB 分期
TNMB staging (CTCL)
皮膚 T 細胞淋巴瘤(MF/SS)分期。T（皮膚）+ N（淋巴結）+ M（內臟）+ B（血液）。B2 ≥ 1000/μL 自動為 SS。
CTCL 文章 →

2 · 機轉 / 細胞激素

機轉
IL-4 / IL-13
Interleukin 4/13 (Th2)
異位性皮膚炎、過敏性氣喘、CRSwNP 的核心發炎細胞激素。Dupilumab 阻斷 IL-4Rα，同時關掉 IL-4 + IL-13 訊號。
異膚文章 →
機轉
IL-17 / IL-23
Interleukin 17 / 23 (Th17)
乾癬、乾癬性關節炎、化膿性汗腺炎的主要驅動細胞激素。Secukinumab / Bimekizumab 抗 IL-17;Risankizumab / Guselkumab 抗 IL-23。
乾癬文章 →
機轉
IL-31
Interleukin 31 (itch cytokine)
「搔癢細胞激素」。在結節性癢疹、異膚高度活化。Nemolizumab 抗 IL-31R 後癢感 1-2 週內顯著改善。
PN 文章 →
機轉
JAK / STAT 路徑
Janus Kinase / STAT pathway
細胞激素受體下游細胞內訊號傳遞路徑。JAK1-3 + TYK2。JAK 抑制劑(Baricitinib、Upadacitinib、Abrocitinib、Ritlecitinib)阻斷此路徑。
生物製劑文章 →
機轉
TNF-α
Tumor Necrosis Factor-α
慢性發炎主軸細胞激素。Adalimumab、Etanercept、Infliximab、Certolizumab 為 TNF-α 抑制劑、用於乾癬、HS、PsA、IBD。
生物製劑文章 →
機轉
PIH / PIE
Post-inflammatory Hyperpigmentation / Erythema
發炎後色素沉著(PIH，棕黑）或紅斑(PIE，紅）。亞洲人 PIH 風險高、雷射 / 痘痘後常見。
肝斑文章 →
機轉
Koebner 現象
Koebner phenomenon
受傷 / 摩擦 / 抓癢處誘發新病灶。常見於白斑、乾癬、扁平苔癬。手術前白斑必須穩定 1 年才適合移植。
白斑文章 →
機轉
Th1 / Th2 / Th17
T helper 1/2/17 cells
輔助 T 細胞分支：Th1 = 細胞免疫（感染防禦）、Th2 = 過敏 / 異膚、Th17 = 乾癬 / HS / PsA。
生物製劑文章 →

3 · 重要藥物

藥物
Dupilumab（度普利尤單抗 / 杜避炎）
anti-IL-4Rα mAb
第一個皮膚科廣譜生物製劑。FDA 適應症：異膚 ≥ 6 個月、結節性癢疹、氣喘、CRSwNP、嗜酸性食道炎。每 2 週 1 針。
用法 →
藥物
Nemolizumab(2024 FDA)
anti-IL-31R mAb
2024 FDA 核准的結節性癢疹專用生物製劑。每 4 週 1 針（優勢：比 dupilumab 少注射）。
用法 →
藥物
Omalizumab(Xolair / 樂無喘）
anti-IgE mAb
慢性自發性蕁麻疹(CSU)第二線。300 mg q4w，反應不佳可加量至 600 mg q2w(off-label)。
用法 →
藥物
Baricitinib(Olumiant / 愛滅炎）
JAK 1/2 inhibitor
第一個 FDA / EMA 核准的圓禿口服 JAK 抑制劑（成人重度）；亦用於異膚、類風濕。
用法 →
藥物
Ritlecitinib(Litfulo / 麗扶柔）
JAK 3 / TEC inhibitor
≥ 12 歲圓禿適應症。200 mg/day × 4 週 loading → 50 mg/day 維持。
用法 →
藥物
Risankizumab(Skyrizi / 喜開麗）
anti-IL-23 p19 mAb
乾癬 / PsA / 克隆氏症生物製劑。每 12 週 1 針（優勢：注射間隔長）。台灣健保有條件給付。
用法 →
藥物
Bimekizumab(Bimzelx)
anti-IL-17A/F mAb
雙重 IL-17 抑制(A + F)。乾癬 PASI 100 達成率最高的生物製劑(60%+ 16w)。
用法 →
藥物
Deucravacitinib(Sotyktu)
selective TYK2 inhibitor
第一個選擇性 TYK2 抑制劑口服乾癬藥。較傳統 JAK1-3 安全性更好（無 ORAL Surveillance 警示）。
用法 →
藥物
Brentuximab vedotin(Adcetris / 安瑞凡）
anti-CD30 ADC
CD30+ 皮膚 T 細胞淋巴瘤(MF / pcALCL)。ALCANZA 試驗：ORR4 56% vs 13%。
CTCL 用法 →
藥物
Mogamulizumab(Poteligeo)
anti-CCR4 mAb
Sézary syndrome / 進展期 MF。MAVORIC 試驗中位 PFS 7.7 vs 3.1 月。
CTCL 用法 →
藥物
Ruxolitinib 1.5% cream(Opzelura)
topical JAK 1/2 inhibitor
2022 FDA 核准的白斑外用藥(≥ 12 歲、NSV、≤ 10% 體表）。52 週 50% 達 F-VASI 75。
白斑用法 →
藥物
Clascoterone(Winlevi)
topical androgen receptor antagonist
2020 FDA 核准的外用抗雄激素痘痘藥。40 年來第一個新機轉外用痘痘藥。
痘痘用法 →
藥物
低劑量口服 Minoxidil(LDOM)
low-dose oral minoxidil
≤ 5 mg/day 不影響血壓劑量。女性 1.25-2.5 mg、男性 2.5-5 mg(Olsen 2025 JAAD 共識）。
用法 →

4 · 疾病分型

分型
Mycosis Fungoides(MF)
蕈狀肉芽腫
皮膚 T 細胞淋巴瘤主要型（占 75%)。斑塊期(patch)→ 厚斑期(plaque)→ 結節期(tumor)三階段。
CTCL 文章 →
分型
Sézary Syndrome(SS)
紅皮症型 CTCL
MF 紅皮症 + 血液 T 細胞侵犯。≥ 80% BSA 紅斑 + Sézary 細胞 ≥ 1000/μL。預後較差。
CTCL 文章 →
分型
CSU
Chronic Spontaneous Urticaria
慢性自發性蕁麻疹（風團 ≥ 6 週、無外因）。50% 在 1 年內、80% 在 5 年內自然緩解。
蕁麻疹文章 →
分型
SV / NSV
Segmental / Non-Segmental Vitiligo
白斑分節型(SV)vs 非分節型(NSV)。SV 預後較好、適合手術;NSV 對 ruxolitinib 反應好。
白斑文章 →
分型
玫瑰痤瘡 4 表現型
Rosacea phenotypes (Clanner 2022)
表現型分類（取代舊亞型 I-IV):持續性紅斑、丘疹膿皰、毛細血管擴張、鼻贅。眼部酒糟為合併症。
酒糟文章 →

5 · 檢查 / 處置

處置
皮膚切片 + 免疫組織化學
Skin biopsy + IHC
疑似 CTCL / 大皰病 / 紅斑性狼瘡。常用 IHC 標記：CD3/CD4/CD8/CD30/CD20。
CTCL 文章 →
處置
TCR 重排
T-cell Receptor gene rearrangement
皮膚切片送檢驗 T 細胞單株性(monoclonality)。MF 早期診斷必備。
CTCL 文章 →
處置
Wood 燈 / 皮膚鏡
Wood lamp / Dermoscopy
Wood 燈：無創照射、白斑變更亮、Tinea versicolor 黃綠螢光。皮膚鏡：10× 放大鏡輔助痣 / 黑色素瘤 / 圓禿診斷。
白斑文章 →
處置
NB-UVB 光療
Narrow-band UVB phototherapy
311-312 nm 窄波。乾癬、白斑、結節性癢疹、廣泛異膚的標準光療。每週 2-3 次。
乾癬文章 →
處置
308-nm 準分子雷射
308-nm Excimer laser
局限性白斑、乾癬、頑固異膚的精準光療。比 NB-UVB 劑量高、療程短。
白斑文章 →
處置
病灶內類固醇注射
Intralesional corticosteroid (ILK)
最常用 Triamcinolone acetonide(TA)5-10 mg/mL。圓禿、肥厚疤、痘痘結節標準處置。每 4-6 週 1 次。
圓禿文章 →

6 · 常見症狀

症狀
苔癬化
Lichenification
慢性反覆抓癢導致皮膚增厚、皺紋加深、紋路明顯。常見於異膚、結節性癢疹、神經性皮膚炎。
異膚文章 →
症狀
水皰
Vesicle / Bulla
皮膚內含液體的隆起病灶。< 0.5 cm = vesicle、≥ 0.5 cm = bulla。常見於汗皰疹、單純皰疹、水痘、自體免疫大皰病。
皮蛇文章 →
症狀
膿皰
Pustule
內含膿液（白色 / 黃色）的隆起病灶。常見於丘疹膿皰型酒糟、痘痘、毛囊炎。
酒糟文章 →
症狀
蝴蝶徵象
Butterfly sign
背部上中央出現「三角形未受波及區」（因手抓不到）。結節性癢疹、慢性癢疹特徵。
PN 文章 →
症狀
血管性水腫
Angioedema
皮下深層腫脹、常見於眼瞼、嘴唇、手腳。40% 慢性蕁麻疹病人合併。喉頭水腫為急症。
蕁麻疹文章 →
症狀
獅面 leonine facies
Leonine facies
臉部廣泛浸潤性紅斑與皮膚增厚、呈「獅子臉」外觀。可見於 MF 結節期、痲瘋病、淋巴瘤。
CTCL 文章 →
症狀
三色性 / 融合性
Trichrome / Confetti
白斑活動性指標。Trichrome：中央白 → 過渡色 → 正常;Confetti：融合性小白點。預示快速進展。
白斑文章 →
