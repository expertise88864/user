輸入 GitHub Personal Access Token

後台用 GitHub API 直接寫進你的 repo (expertise88864/user)。需要 PAT 一次，儲存在你瀏覽器的 localStorage，不會傳到任何第三方。

怎麼產生 PAT?
① https://github.com/settings/tokens
② 點 "Generate new token (classic)"
③ 名字隨便填，Expiration 選 90 天 / No expiration
④ 勾 repo 全部權限
⑤ Generate → 複製 token 貼下面

token 只存在這個瀏覽器
