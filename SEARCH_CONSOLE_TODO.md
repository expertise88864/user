## 額外動作（一次性）

- [ ] Search Console → Sitemaps → 確認 `https://chendermatologist.com/sitemap.xml` 已提交（重新提交一次以更新命名空間修正後的版本）
- [ ] Search Console → Settings → 確認 ownership verification 仍有效
- [ ] Bing Webmaster Tools → 提交 sitemap（也可以 import from Search Console）
- [ ] IndexNow → 註冊 + push（會同時通知 Bing、Yandex、Naver）
- [ ] Google Analytics 4 → Admin → Data Streams → Web → 「定義內部流量」加入您的家／診所 IP
- [ ] GA4 → Admin → Data Filters → 啟用「Internal traffic」過濾（以排除 traffic_type=internal）
