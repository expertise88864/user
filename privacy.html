隱私權政策

最後更新：2026 年 10 月 5 日

歡迎使用 ChenDermatologist（以下簡稱「本網站」）。我們重視您的隱私權，並致力於保護您在本網站使用過程中可能涉及的個人資料。本政策說明我們收集哪些資訊、如何使用、以及您的權利。

1. 我們收集哪些資訊

1-1 您主動提供的資訊

公開閱讀不需要註冊帳號或提供姓名、身分證、病歷。作者後台的登入、草稿與媒體功能屬於另外的管理流程。如果您透過頁尾電子郵件聯絡，您主動提供的內容會經由電子郵件服務處理。

1-2 系統自動收集的資訊

Vercel 提供網站代管。載入網站及第三方資源時，服務提供者可能接收 IP 位址、瀏覽器、頁面路徑、時間及其他必要的技術資料，用於提供服務、維護效能與安全。不同服務的處理與保存方式，請參閱各服務的隱私說明。

1-3 Cookie 使用

本網站使用 Cookie 與瀏覽器儲存資料：

  • 語言偏好 Cookie：dn_lang 記錄中文／英文選擇，有效期 365 天。
  • 本機儲存：記住語言、主題、字體大小、已閱讀文章及閱讀位置。作者草稿也可能暫存在登入使用的瀏覽器。
  • 第三方分析 Cookie：GA4 可能使用識別碼及 Cookie，詳見下方服務說明。Microsoft Clarity 程式目前已停用。

您可以透過瀏覽器設定清除 Cookie 與網站儲存資料，或封鎖第三方 Cookie。清除後，偏好與本機閱讀記憶可能會重設；作者也應先確認草稿已保存。

2. 第三方服務

2-1 Google Analytics 4（GA4）

本網站使用 GA4 了解頁面瀏覽、閱讀進度與站內導覽，以改善內容與閱讀體驗。本站自訂分析事件不包含您輸入的搜尋詞，這些自訂事件中的頁面與連結網址會移除查詢字串與片段。GA4 仍可能處理 Cookie、技術識別碼、裝置及概略地區等資料；這不表示所有分析資料都完全匿名。詳見 Google 隱私權政策。

2-2 Microsoft Clarity（已停用）

本網站目前不載入 Microsoft Clarity，不啟用其點擊錄製或工作階段重播。停止載入程式不會自動刪除服務端原有的資料；如需查詢服務提供者的資料處理方式，請參閱 Microsoft 隱私權聲明。

2-3 Google Search Console / Bing Webmaster (SEO)

Google Search Console 與 Bing Webmaster Tools 用於確認網站所有權、提交 sitemap 及查看搜尋表現。本網站不會因為使用這些管理工具而要求讀者提供個人資料。

2-4 Google Fonts 與本地 CSS

網站字體可能由 Google Fonts 載入；主要版面樣式使用本站自有的本地 CSS 檔案，不再依賴 Tailwind CDN。Google Fonts 在載入資源時可能會看到您的 IP。

2-5 Vercel Speed Insights（效能量測）

本網站使用 Speed Insights 量測載入、互動與版面穩定性。Vercel 說明，其效能資料包含頁面路徑、裝置與瀏覽器類型、國家及 Web Vitals 等資料點，不用來重建跨頁瀏覽工作階段。這與網站代管的一般技術日誌不同。詳見 Speed Insights 隱私說明。

2-6 廣告狀態

目前 AdSense 廣告程式已停用；日後啟用時會更新本頁說明。

3. 我們不會做的事

  • 本網站不會販售、出租、交換您的任何個人資料給第三方。
  • 公開文章閱讀不要求提供醫療紀錄、症狀描述或照片。
  • 如果您主動來信，我們可能以電子郵件回覆；不會因為您閱讀文章就取得您的電子郵件地址。

4. 您的權利

如有資料查詢、更正、刪除或停止處理的問題，請使用網站頁尾的電子郵件聯絡。第三方服務的資料處理與退出方式，請參閱各服務的隱私說明。

清除瀏覽器 Cookie 與網站儲存資料，只會移除這台裝置上的偏好與識別資料，不會自動刪除已傳送給第三方服務的資料。服務提供者保存的資料，須依其程序提出相關請求。

5. 兒童隱私

本網站內容適合一般成人閱讀。本網站不主動收集 13 歲以下兒童的個人資料。如您是兒童的監護人，並認為您的小孩的資料可能被本網站誤收，請透過下方聯絡方式告知我們。

6. 政策更新

我們可能不定期更新本政策以反映服務、法規或技術變化。重大變動會於本頁面公告。建議您定期檢視。

7. 聯絡我們

對本隱私權政策有疑問，請使用網站頁尾的「聯絡 Email」。您也可在 關於作者 頁了解本網站的教育用途。

8. 醫療免責

請注意：本網站所有衛教內容僅作為一般教育參考，不能取代醫師面對面的問診、檢查與處方。任何用藥、停藥、調整劑量或就醫決定，請以您的主治醫師判斷為準。
